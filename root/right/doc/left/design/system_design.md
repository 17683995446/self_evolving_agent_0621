# 系统架构设计

## 概述

自驱永续进化Agent采用三阶段闭环架构：

- Phase 1: 感知-驱力-预测闭环
- Phase 2: 任务-决策-记忆闭环
- Phase 3: 进化-快照-回滚闭环

## 目录结构

满二叉树结构确保每个目录最多2个子目录。

## 核心模块

### 感知模块 (sensory)
采集系统指标，标准化处理，噪声过滤。

### 驱力引擎 (drive)
计算安全/收益/能效三大驱力，动态权重调整。

### 预测模块 (predict)
三层预测架构：底层EMA、中层岭回归、高层聚类。

### 任务池 (task)
基于驱力缺口生成任务，优先级队列管理。

### 决策模块 (decide)
70%利用+30%探索双决策机制，资源平衡。

### 记忆模块 (memory)
状态缓存+SQLite持久化，支持趋势分析。

### 进化模块 (evolve)
快照管理、重构引擎、特征引擎、评审引擎。
